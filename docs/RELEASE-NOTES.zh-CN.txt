Locus 0.5.0 (63) — Agent 抓包诊断闭环

新增 Requests 工作流：
1. 应用发现：按名称、图标、签名ID选择实际联网应用；仅按真实包路径关联运行中的嵌入辅助应用，未知归属不猜测。最近主机只供审阅。
2. Check preparation：扩展心跳、记录同步、准确配置确认、证书准备、审批范围及预判阻断。只读检查，不自动 Connect、安装信任或批准正文。
3. Investigate & share：HTTP/传输错误、状态码、未完成/截断、耗时中位数/p95、失败和慢请求、准确请求/连接ID。空结果不代表没有流量。
4. HTTP 会话对比：同一准确应用、已结束、按时间先后且不重叠的两次 Sessions；显示计数、耗时与窗口/配置差异，不自动宣称修复成功。
5. AI/流式信息：只展示保留JSON/SSE中的模型、接口报告的token用量、数据帧数和实测首个响应字节时间；不估算token，不把首字节当首个模型token。
6. 分享：默认不包含正文、目标地址、URL、路由名称和头部，保留应用、时间及证据ID；可显式包含脱敏样本，先预览再通过原生对话框保存JSON。超过128KiB预览需先缩小到会话。
