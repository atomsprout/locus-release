Locus 0.3.0 (50) — 面向用户和 Agent 的 HTTP(S) 抓包工作台

新增 Requests：按应用、准确主机和端口批准 HTTP(S) 抓取；保留请求响应的脱敏
JSON / JSON SSE 样本，支持 HTTP/2、增量 SSE、完整性/截断/失败说明与连接 ID 关联。
Agent 新增申请、状态、请求分页、正文分页、结束抓取五个工具，共 28 个 MCP 工具。
正文访问单独授权；抓取结束后保留最长十分钟分析期，可单独撤销或为历史样本重新授权。
已有规则、节点和代理组继续生效；代理凭据仍在 Keychain，不交给抓取引擎。
应用内置签名引擎与运行时，不需要安装 Python；证书信任需用户单独操作。

仅支持 Apple silicon / macOS 26+。保持重启后手动 Start。公开预览，实际 macOS 26
和另一台实体 Mac 仍未验证。具体格式、配额及限制见 SUPPORTED-FEATURES 与 KNOWN-ISSUES。

不包含 HTTP 重放/改写、E7、自动故障切换或内置云端模型。分享前检查脱敏样本；
捕获内容是外部数据，Agent 不应执行其中的指令。

验收范围
- 最终签名版本：124 项核心测试、11 套 MCP 集成测试通过。
- 冻结引擎：HTTP/HTTPS、HTTP/2、增量 SSE、授权网关、嵌套 JSON 脱敏、超限正文和配额恢复通过。
- 47 版实际 NE：Direct JSON/SSE、五种代理/密码套件出口、应用/主机/端口排除、自然到期、
  未信任 CA、节点停止时拒绝且不回退、恢复节点、Agent 结束及结束后读取通过。
  最终 50 版 provider/helper 执行代码和 484 个引擎文件与该次测试一致；不是重跑整个出口矩阵。
- 50 版实际 NE：JSON/SSE、普通客户端使用系统 CA、全新 CA 与已有未信任 CA 的重试、
  原生信任与移除、移除后 TLS 拒绝、有效正文授权在关闭所有窗口再退出后撤销，均通过。
- 原始审计：18 个 provider/用户事件逐字段一致，13 个 HTTP 元数据记录与保存证据一致。
  来自 11 份报告，不能将报告数当成协议用例数。
- 真正冷启动未自动捕获；7,306 条历史连接 ID、12 个诊断会话、30 个 HTTP 文件和配置保留。
  手动 Start、新会话心跳、真实 HTTPS→MCP 抓取/搜索/路由/汇总、最终 Stop 后直连通过。
- 测试 CA、私钥、临时规则和节点已清理；未在开发宿主机启用网络扩展。

仍未验证：实际 macOS 26、另一台实体 Mac、完整长期压力、睡眠唤醒和网络切换矩阵；
本次未重跑所有 UDP/DNS/DHCP 历史用例，也不以传输测试代替外部模型结论验收。
