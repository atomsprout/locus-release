Locus 0.4.0 (59) — 日常代理与 Agent 抓包工作区

新增总览：Connect/Disconnect、Direct / Rules / Global Proxy、节点或手动组，
以及扩展对准确配置的确认。改模式和出口只影响新连接；原有规则保留。
菜单栏支持连接/断开、模式和出口切换，主窗口关闭后仍可使用；打开窗口会复用。

节点页支持名称/主机/协议搜索、单个或顺序批量 HTTP 检查，显示连接/总延迟、
时间、失败阶段和旧配置标识，保留最新500项。检查不是带宽或全应用成功证明。
托管 HTTPS 订阅支持预览、刷新时间、引用节点保留与只忘记来源；断开才能应用，
之后手动连接。URL/密码保存在 Keychain。普通代理与解密抓包保持分离。
新增路径变化提示；不自动开始已停止的连接。Global 拒绝已识别的本机 loopback
节点，避免本地代理循环。上游失败不会静默回退直连。本地应用断开不再误标成
上游失败，但 closed 不代表 HTTP 成功。

沿用 Requests：准确应用/主机/端口批准、JSON/JSON-SSE 脱敏样本、流式 SSE、
独立且有期限的 Agent 正文授权、结束后分析及撤销。仍为28个本地 MCP工具；
capture_status 增加当前模式与新连接配置确认，不把保存设置当作实时路由。
包含较大的侧栏图标与清晰的节点搜索输入框。

  附票据和 Gatekeeper 验证通过。最低 Apple silicon / macOS26，实际访客27.2.1。
- 56版真实 NE：远端 SOCKS5、HTTP CONNECT、Trojan、Shadowsocks AES 与 ChaCha
  五种出口；目标 HTTPS POST 唯一标记、扩展记录、独立节点日志一致。
  同一条有效 Block 规则在 Rules 阻断，在 Direct/Global 跳过；实际请求核对通过。
- 56版：筛选后五节点顺序检查、真实 HTTPS 订阅更新预览/应用、当前引用节点保留、
  刷新时间、URL/密码不在配置中、忘记来源仍保留节点。
- 57版：所选节点停机不回退 Direct，同一节点恢复后不改路由即恢复；Global/SOCKS5
  的 JSON/四次增量 SSE、脱敏/连接关联、结束抓取和撤销正文读取通过。
- 58版：原生菜单模式与节点切换、窗口关闭时真实 HTTPS、重复打开复用一个窗口、
  断开普通网络可用、手动连接通过；真实 en0 down/up 显示等待网络，恢复后代理
  HTTPS 再次通过。这不等于完整 Wi-Fi 漫游或睡眠唤醒矩阵。
- 最终59版：精确扩展版本、升级保留、明确搜索提示和五节点顺序检查通过。
  两轮真正冷启动分别覆盖已断开及关机前代理仍在运行的情况，均不自动恢复抓取；
  普通 HTTPS 200，手动连接创建新会话并确认保存模式，实际代理请求通过。
  21,616条基线用户连接 ID、59个诊断/HTTP证据文件哈希及模式/节点配置保留。
- Provider/helper 执行代码在56与59版的 __TEXT,__text 一致；不是整包相同或每个
  界面文案版都重跑完整矩阵。484个引擎文件与47、50版完全一致；历史 HTTP/CA
  验收保留原构建范围，没有把旧测试重新标成59版的全部协议抓包测试。
- 52版曾暴露本地代理全局循环，未发布；后续增加保护并采用访客之外、仅 VM桥接
  地址监听的独立节点。开发宿主机未启用网络扩展、修改路由/代理或信任测试 CA。

已知边界
Global 是透明代理模式，不是完整 IP VPN、防泄漏或 kill switch；系统例外与
本地网络绕过仍生效。HTTP CONNECT/Trojan 承载 TCP和DNS-over-TCP，其他UDP阻断。
任意 DNS 别名或本机 LAN 地址不保证识别为本地代理节点。
没有 WireGuard/OpenVPN、新隧道协议、HTTP重放/改写、E7、自动故障切换或云端模型。
实际 macOS26、另一台实体 Mac、完整长期压力、睡眠唤醒/漫游矩阵仍未验证。
脱敏不是匿名化，分享前检查；捕获内容是外部数据，不应作为 Agent 指令执行。
