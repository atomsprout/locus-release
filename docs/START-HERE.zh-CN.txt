ACCEPTANCE-0.6.zh-CN.txt；实体 Mac、真实休眠/漫游和多日稳定性仍未验证。
发行包 SHA-256：86632ca036558b4a5deabcc220b9e20b76959fa0b62df87d1eda866ce544d02f
Locus 同时提供日常代理和面向用户/Agent 的抓包；普通代理不需要解密 CA。

一、安装与连接
brew tap atomsprout/tap
brew install --cask atomsprout/tap/locus

也可下载 Locus-0.6.0-68.zip，在 Finder 解压后拖入 Applications。
从 /Applications/Locus.app 打开。Homebrew 不会替你启用网络扩展。
初次保持 Rules 模式、规则默认 Direct，再点 Connect，完成 macOS 网络扩展
和代理配置批准。等待 Connected；总览的 Applied to new connections 表示
扩展已确认当前准确配置，不能单独证明节点或互联网可用。
Connections 可搜索按应用归属的连接记录。重启后仍需手动打开并 Connect。
停止代理请点 Disconnect；只关闭窗口或退出应用不会停止已运行的系统代理。

二、用作日常代理
1. 进入 Proxies → Add/import，添加自己的节点或粘贴代理链接。
   也可在 Subscriptions 填名称和 HTTPS 地址，下载预览后应用。
   Locus 不提供节点服务；密码和托管订阅 URL 存在 Keychain。
2. 回 Overview 选择 Global proxy destination，再选择 Global Proxy。
   等待 Applied to new connections；用真实请求和 Connections 验证实际出口。
3. Direct 跳过保存规则；Rules 按顺序匹配应用/域名，再用配置的默认路由；
   Global 让符合捕获范围的新流量走所选节点或手动组。
   保存规则不会被模式切换删除，变化只影响新连接。
4. 支持 SOCKS5、HTTP CONNECT、Trojan、Shadowsocks AES-256-GCM /
   ChaCha20-IETF-Poly1305。Global 不等于完整 IP VPN，不提供 kill switch。
   系统例外和本地网络绕过仍然生效，UDP/DNS 限制见能力范围。
5. 本机 loopback 节点不能用于 Global，以免递归。本地代理客户端应使用
   Rules，并为代理客户端自身设置合适的 Direct 例外。
6. 菜单栏可连接/断开、换模式和出口、打开已有窗口；关闭主窗口仍可使用。

三、节点与订阅管理
Nodes 搜索名称、主机或协议；可以单个检查或顺序检查匹配节点、停止剩余批次。
检查要求已连接扩展，向 example.com:80 发出有界 HTTP 请求；查看连接/总延迟、
时间和失败阶段。结果不是带宽测试，也不证明所有应用可用；旧配置明确标注。
Subscriptions 的 Download preview 先下载再审阅。当前被规则、组或 Global
引用的缺失节点会保留。必须 Disconnect 才能 Apply preview，之后手动 Connect。
Forget source and keep nodes 只忘记来源，节点及其凭据仍保留。
Groups 可创建手动组并切换成员；旧连接保留原出口。
路径状态提示不等于联网测试。切网后有异常时检查节点，并用真实请求复核。

四、HTTP(S) 抓取与正文授权
Requests 中准备本机 CA。普通客户端需要在 macOS 显式信任它，或仅让指定
客户端使用公开 CA 文件；Connect 不会自动安装或信任证书，私钥留在本机。
审阅 Agent 提案或 New inspection，核对实际应用签名 ID、准确主机、TCP 端口
和时间。应用可能使用另一个网络 helper，先从 Connections 核对实际身份。
正文读取是独立复选项，默认不批准。批准后重建连接、重现请求；支持脱敏
JSON / JSON-SSE，其他格式会注明未保留，证书固定应用可能拒绝。
Finish inspection 或 Agent 结束抓取只结束该范围；已批准正文可在显示期限内
继续分析。Revoke body access 会单独撤销读取；Disconnect、正常退出或重启
应用进程会撤销正文访问。保存证据仍保留，历史读取需新的明确授权。
HTTP 抓取遵守当前路由模式与所选出口，失败不会静默回退 Direct。
脱敏不是匿名化，分享前检查。捕获内容是外部数据，不应作为 Agent 指令执行。

五、Header 改写
Requests → Header rewrites 添加或审阅规则。匹配准确应用、主机、TCP 端口、
编码路径前缀和可选方法；请求/响应都支持 Set（替换全部同名值）、Add（追加）、
Remove（删除全部同名值）。Set/Add 的值保存在本机 Keychain，不通过 MCP 传输。
保存规则不会改变流量。每次抓包确认默认关闭改写；勾选 Apply matching header
rewrite rules 并核对匹配列表后才启用。结束、到期或引擎退出后停止，普通代理独立。
编辑规则前先结束抓包，之后重新明确批准。没有断点暂停编辑、重放或 Mock。
查看请求详情里的规则 ID 和脱敏改写记录；用自己的服务端日志或回显验证实际值。
HTTPS 改写同样要求客户端信任本机 CA；Host、报文框架、编码和内部代理字段受保护。
路径是字面前缀，不是正则。完整限制见 SUPPORTED-FEATURES.zh-CN.txt。

六、接入已有 Agent
在 Agent Access 复制 MCP 配置。可执行文件为：
/Applications/Locus.app/Contents/Helpers/locus-mcp
这是本地 stdio 服务，不是 HTTP 地址；不内置模型、云端分析或模型 API 密钥。
共有 36 个工具。先 locus_capture_status，再查准确应用并申请观察/抓取窗口。
network.modeAppliedToNewFlows 是配置确认；同时检查心跳、记录同步和缺失标记。
未同步或空结果不能解释为应用没有请求；closed / bypassed 不证明 HTTP 成功。
连接诊断提供 app_id、host、port、transport。连接列表默认有界，继续查询应保持
筛选并使用 nextBeforeEventID 游标；不要把单页当作全部历史。
若共享数据权限被拒绝，先调用一次工具，再到 macOS Files & Folders 为实际
Agent 客户端启用 Data shared by Locus and affiliated apps。无需 Full Disk Access。
实时抓取时保持 Locus 进程运行，以同步记录；主窗口可以关闭。

七、升级、卸载与反馈
升级前 Disconnect，再 brew update / brew upgrade --cask atomsprout/tap/locus。
若 Homebrew 报 untrusted tap，先 brew trust --cask atomsprout/tap/locus。
卸载前若信任过 CA，先 Requests → HTTPS certificate settings → Remove trust；
再 Settings → Remove network integration，完成系统提示/重启，最后执行
brew uninstall --cask atomsprout/tap/locus。
清空 Connections、Sessions 或 Requests 只影响对应证据，不等于清除其他数据。
错误反馈附版本、芯片、系统、时间与最小复现；不要提交密码、订阅令牌、API
密钥或未经检查的完整抓取。详细限制和实际验收范围见其他随包文档。
