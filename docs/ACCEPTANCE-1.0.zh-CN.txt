Locus 1.0.0 (70) 正式版验收范围

最低系统 macOS 26.0，Apple silicon。本版最终包只在一台 macOS 27.2.1 (26B131) 虚拟机上验收；不代表已测过 macOS 26、26.0 本身或实体 Mac。macOS 26.6.2 虚拟机最近一次验收的是 0.6.0 (68)。

验收对象是同一份 Developer ID 签名、Apple 公证并附票的 ZIP：
Locus-1.0.0-70.zip
SHA-256: 2b744b3a7651facac6e56454cbb4e5a241f3dc37f583c427b6c195ac434caa8b

1.0 相对 0.6 的改动是界面与提示：简体中文界面、文案统一、端口显示、证书说明与抓包确认页的显示修正、首次连接与安装位置提示。网络扩展、抓包引擎和核心路由逻辑没有功能性修改，冻结引擎沿用 0.6 的同一二进制。

本版验证：
- 146 个核心测试、7 个 Python Header 规则测试、14 套针对签名 helper 的 MCP 集成测试。
- 新装走查：在全新虚拟机上以带隔离标记的下载方式安装 0.6.0 (68)，Gatekeeper 放行；按 Homebrew 的隔离标记安装时应用直接从 Applications 运行，Connect 弹出系统扩展批准，批准后连接并出现按应用归属的连接记录。
- 升级：0.6.0 (68) → 内部 69 → 1.0.0 (70)。先 Disconnect，替换应用，手动 Connect；系统扩展精确版本为 1.0.0/70，无需再次批准；配置、Header 规则及其 Keychain 值、已保存证据保留。
- SOCKS5 与 HTTP CONNECT 两种节点的真实路由，以及不带任何 CA 参数的普通 HTTPS。
- 抓包默认不改写；明确勾选后请求 Set / Add / Remove、响应 Set / Remove、路径不匹配不改写、HTTPS 改写、增量 SSE；用独立服务端记录的 nonce、Header 和来源地址核对。
- 结束抓包后立即发起普通请求和 16 个并发请求，改写全部停止，Global 代理继续。另测 30 秒范围到期、SSE 中途强制结束引擎后抓包与正文授权被撤销。
- 代理节点不可用时请求失败，独立服务端没有收到该请求，没有偷偷直连；节点恢复后路由恢复。
- 10 次手动 Disconnect / Connect，每次都是新的扩展会话并成功回显。
- 持续代理 601 秒、2336 次成功 nonce 回显（每批 8 个请求，批间暂停 2 秒，HTTP CONNECT 节点）；结束时事件写入失败为 0、记录同步正常。这是短时有界运行，不是饱和吞吐、长时抓包压测或 0.6 那样的 30 分钟运行。
- 实际冷启动：重启前处于 Global 已连接；重启后不自动连接、不自动抓包或改写、无 Agent 正文授权，配置与已保存证据的哈希不变。手动 Connect 并再次勾选后，原 Keychain 值生效。
- 简体中文界面：各页面、抓包确认、Header 规则、节点检查在中文下实际显示并完成上述操作。
- 清理：删除测试 Header 规则及其 Keychain 值，恢复原始配置字节，移除本次生成的 CA 私钥；无残留抓包或正文授权。未向系统或登录钥匙串添加测试 CA 信任。

观察到但未下结论的现象：持续代理期间网络扩展内存从约 20 MiB 升到约 192 MiB，10 分钟内没有回落；应用内存基本不变。0.6 的 30 分钟运行里同一扩展代码的峰值约 142–154 MiB 且会回落。本版扩展代码未改动，这次运行不足以判断它是否会继续增长。

本版没有执行的项目：
- macOS 26 虚拟机：宿主机磁盘不足以再建第二台。
- 访客网卡断开/恢复、启动取消竞态：前者需要管理员密码，后者未安排。
- 系统钥匙串 CA 信任与移除、Remove network integration 与完整卸载：需要输入管理员密码，未执行。
- 全新安装 1.0 时的首次扩展批准：批准步骤只在 0.6.0 (68) 上实测；1.0 走的是升级路径。
- Trojan、Shadowsocks、完整 UDP/DNS/DHCP/IPv6 矩阵：沿用历史构建证据。
- 实体机、真实休眠唤醒/Wi-Fi 漫游、多日运行、macOS 26.0。

本产品是规则代理和有授权边界的 HTTP 调试工具，不能承诺完整 VPN、全流量覆盖、Kill Switch 或防泄漏。不支持暂停断点编辑、重放、Mock、任意请求体/URL 修改或内置 AI 推理。证书固定应用可能无法解密；正文脱敏是尽力处理，服务端可能把 Header 值回显到正文。

复核源码、测试与原始运行证据留在私有源码仓库/本地，不随公开发行仓库发布。
