Locus 1.0.0 (70) 已知限制

1. 要求 Apple silicon / macOS 26+。验收所用的具体系统、构建、项目和持续时间见
   ACCEPTANCE-1.0.zh-CN.txt。1.0 最终包只在 macOS 27.2.1 虚拟机验收；macOS 26
   虚拟机的最近一次验收是 0.6.0 (68)。实体 Mac、真实休眠唤醒、Wi-Fi 漫游、
   macOS 26.0 本身和多日持续运行不能由短时虚拟机验收代替。
   简体中文界面不覆盖路由解释正文、节点协议名和 MCP 返回给 Agent 的文字。

2. Global 是透明应用代理，具有系统例外和本地网络绕过，并非完整 IP VPN。
   不提供 WireGuard/OpenVPN、系统级 Kill Switch、完整 DNS/IPv6 防泄漏或自动故障切换。
   HTTP CONNECT/Trojan 只承载 TCP 与 DNS-over-TCP，其他 UDP 明确失败。
   节点不可用时不会自动回落 Direct，也不代表系统全部流量均被阻止。

3. 本机 loopback/localhost/wildcard 节点不能用于 Global，避免递归。DNS 别名或本机
   LAN 地址不保证自动识别。本地代理客户端应使用 Rules，并为其自身明确设置直连。
   节点/模式变化只影响新连接；旧连接保留原路线。完整节点兼容性取决于服务端实现。

4. HTTPS 需显式信任本机 CA，也可以由特定客户端使用公开 CA 文件。
   不绕过证书固定；不解密 QUIC/HTTP3、WebSocket 帧，不提供 gRPC 解码，
   不支持跨主机 HTTP/2 连接合并、上游自签名根证书或 mTLS 身份配置。
   抓包前已有连接可能不再进入扩展，重现时应重新建立连接。

5. Header 规则保存后仍不生效；每次抓包须明确勾选启用。只在准确应用/主机/端口/
   路径/方法/本次范围中生效，结束后停止。编辑规则需先结束抓包。
   路径是编码后的字面前缀，不是正则或路径段匹配。Set 替换全部同名值，Add 追加。
   禁止修改路由、报文框架、编码及内部代理 Header；没有断点暂停、重放、Mock 或 E7。
   Agent 只提出匹配规则；替换值由用户在 GUI 输入，不通过 MCP 传输或读取。

6. 正文只保留有限的脱敏 JSON/JSON-SSE 样本，每侧 64 KiB，最多 1,000 条/128 MiB。
   不保留任意文本/二进制、无效编码或超限正文。界面加载最新 200 条，MCP 可分页。
   脱敏为尽力处理，不能保证匿名化或检测所有秘密；响应可能在任意字段回显 Header 值。
   改写审计自身不保存替换值；这并不意味着任意响应正文都不会包含秘密。
   同一 macOS 用户已拥有本地文件权限的其他进程，不受 MCP 正文授权策略隔离。

7. 抓包需 GUI 保持运行。结束、到期会中断尚未完成的受检流；独立正文读取授权
   可按批准范围保留最多十分钟。Disconnect、正常退出或重新启动 GUI 会撤销正文授权。
   停止中会等待扩展撤销确认；超时不宣称结束，可再次 Finish 或先 Disconnect。
   丢失、不完整、截断和同步缺口均须保留在诊断结论中。

8. closed/bypassed 不证明 HTTP 成功；节点检查不是带宽测试、HTTPS 校验或应用成功率。
   不同窗口/配置的会话对比不是因果证明。会话配置快照指路由配置，不包含 Keychain
   中的 Header 替换值；路由配置相同不代表 HTTP 改写条件或值相同。应结合实际改写
   规则 ID、请求证据和服务端确认。AI token 只来自保留样本中的 API 报告，
   首响应字节不是首 token。Locus 不内置模型，不保证外部 Agent 的分析、筛选和引用正确。
   抓到的响应永远是不可信数据，不能当成执行命令或批准权限的指令。

9. 连接日志仅保留当前和上一份（各约 8 MiB）；保存会话另有限额。
   不静默删除旧会话或 HTTP 证据，达到上限需手动清理。所有导出均可能保留应用、
   时间、证据 ID 等信息；分享前预览。清空连接日志不会清空保存会话或请求样本。

10. 安装、重启不会自动 Connect。退出 GUI 本身不会停止已运行的网络扩展。
    卸载前先 Disconnect，移除已信任 CA，再在 Settings 移除网络集成。
    macOS 可能把扩展完整卸载延后至重启；不要手工删除系统扩展目录。
    App Group 的 Files & Folders 权限可能在删除/重装后被系统重新拦截，不代表数据丢失。

11. 持续代理时网络扩展的内存会随连接记录增长。1.0 的 10 分钟有界运行里从约 20 MiB
    升到约 192 MiB，期间没有回落；0.6 的 30 分钟运行峰值约 142–154 MiB 且会回落。
    是否会无限增长尚未查明。长时间高流量使用后如发现系统变慢，Disconnect 再 Connect
    会启动新的扩展会话。

历史说明：第 21 版曾因将系统 DHCP 续租路由到 Trojan 而导致 IPv4 租约撤回，已撤回。
当前保留 configd DHCPv4 UDP/67、DHCPv6 UDP/547 固定直连例外；普通应用的同端口不豁免。
历史自然单播续租审计保留其原始构建范围，不能用单次接口恢复或 Request/ACK 代替完整
自然续租/DHCPv6/跨网络验收。较早外部模型案例也出现过筛选、上下文及引用错误；
工具参数收紧不能替代对实际证据和模型回答的核对。
