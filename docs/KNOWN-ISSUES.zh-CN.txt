Locus 0.2.1 (42) 已知限制与待完成验收

1. 第 21 版已撤回：日志确认系统 DHCP 续租曾被选择为 Trojan 并拒绝，
   后续系统撤回 IPv4 租约。本候选加入系统 configd DHCP 的固定直连例外；
   普通应用的相同 UDP 端口仍按规则处理。签名 MCP 的解释测试通过，
   真实自然续租已在第 23、25 版通过独立审计；DHCPv6 与其他网络仍待验证。
   刷新时的 Request/ACK 不代替自然单播续租分支验证。
   原首次 HTTP 失败发生在系统丢失 IPv4 之后、连接到达扩展之前，
   不能再将它简单归为与 Locus 无关的环境故障。

2. 外部模型的回答仍需核对。第 23–28 版 Goose/Qwen 4B 案例曾发生漏筛选、
   上下文溢出、反复压缩、虚构成功次数或抄错 ID。第 29 版将应用参数改为
   顶层必填，并拆出显式全局/未知身份工具。在客户端与服务端均为 16k 的
   一个实际案例中，首次调用参数完整，当前路由、14 条历史记录及引用 ID
   正确，正常完成；但标题仍把 bypassed 错称为成功，后文才否认可证明成功。
   因此只接受这个案例的核心事实，不保证模型叙述无误或其他任务同样可靠。
   客户端输入上限与模型服务端上下文须分别配置；较大上下文占用更多内存。
   bypassed / closed 都不证明应用请求成功；请核对工具范围和原始记录 ID。

3. 当前验收主要来自隔离 macOS 虚拟机，另一台干净实体 Mac 仍待验收。
   Apple 公证与 Gatekeeper 核验通过，不等于所有运行路径都已完成验收。
   本版是公开预览版，实体 Mac 反馈和验收仍待完成。

4. 这是连接元数据工具，没有 HTTPS 请求/响应正文或 HTTP 重放。
   Direct / Block 的字节数和耗时通常未测量，不能把未知值解释成零。

5. 实时 Agent 抓取依赖运行中的 Locus GUI 同步记录。关闭 GUI 后，扩展
   可能继续代理和记录，但用户镜像会滞后，工具可能无法确认新鲜心跳。
   工具显示 captureActive=false 不等于已确认系统代理停用；停止应点 Stop。

6. 当前和上一份日志各约 8 MiB，更早记录会淘汰。没有无限期审计保证。
   即使没看到警告，也不代表覆盖了全部系统流量。按应用归属也可能缺失。

7. HTTP CONNECT / Trojan 不支持普通 UDP。DoH/DoT 不解密；私有 DNS
   改写不能保证内网专用域名可解析。完整协议范围见 SUPPORTED-FEATURES.zh-CN.txt。

8. 代理认证失败时，部分服务端只重置连接，客户端未必能区分具体原因。
   连接记录可能在下一次同步后才出现，立即的空列表不足以判断请求未发生。

9. 代理凭据保存在 Keychain。连接记录保存在本机受权限保护的 App Group；
   配置的 MCP 客户端可读取这些记录。客户端后续如何使用模型和数据取决于
   你自己的配置；Locus 不内置云端 AI 分析服务或模型凭据。

10. 退出 Locus 不会自动停止系统代理；重启后则需手动打开应用并 Start。
   安装、停用与卸载步骤见 START-HERE.zh-CN.txt。

11. 扩展停用后，macOS 可能将完整卸载延后到重启。界面会提示已停用、
    重启完成可能待处理的移除；系统条目可能为 terminated waiting to uninstall
    on reboot。重启后再核对系统状态，不要手工删除系统扩展目录。

12. 删除应用后，macOS 可能拦截客户端读取保留的 App Group 数据。权限拒绝
    不代表数据被清空。重新安装后应重新核对客户端的 Files & Folders 共享
    数据权限；如开关已开仍被拒绝，可关闭再开启这一项并重试。无需为了
    查看连接记录开启 Full Disk Access。

13. 第 31 版将应用、扩展和 MCP helper 的最低部署系统统一降至 macOS 26，
    编译器 API 可用性检查通过。macOS 26 实际授权、联网与生命周期仍待验证；
    历史 macOS 27 测试不能替代 macOS 26 验收。

14. 新会话、节点任务依赖运行中的 GUI 同步。会话达到数量或空间上限会明确提示；
    清空滚动日志不会清空保存会话。最终快照缺失会标记不完整，不能当成完整证据。
15. 节点测试只代表通过该节点的一次受控 HTTP 连通性检查；不是测速、HTTPS 校验或应用成功率。
16. 托管订阅更新需先停止；不支持自动刷新/自动故障切换。含糊的同端点/同名情况不承诺自动识别。
17. 脱敏导出使用稳定别名，并非匿名化；应用标识、时间、证据 ID、端口仍保留。
18. 临时规则批准后优先于普通规则。到期只影响新流，不关闭已经建立的连接；过期条目可手动删除。
