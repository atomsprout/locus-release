Locus 1.0.0 (70) 能力范围

界面
• English、简体中文，跟随系统语言。路由解释正文、节点协议名和 MCP 返回给 Agent 的文字为英文。

日常代理
• Network Extension 透明应用代理；Direct / Rules / Global 三种模式。
• 按应用签名标识、域名/子域名顺序匹配 Direct / Block / Proxy，可暂停单条规则。
• SOCKS5、HTTP CONNECT、Trojan、Shadowsocks AES-256-GCM / ChaCha20-IETF-Poly1305。
• 节点凭据在 Keychain；代理链接、HTTPS 订阅导入；手动订阅刷新预览、手动代理组。
• 节点测试由扩展通过具体节点发出，返回连接/认证/目标连接/HTTP 等阶段。
• 节点失败不会偷偷回落 Direct；不等于系统级 Kill Switch。
• 默认本地网络绕过；系统 DHCP 获取/续租流量有固定直连例外。
• SOCKS5/SS 的 UDP 取决于上游能力；HTTP CONNECT/Trojan 对非 DNS UDP 明确拒绝。
  UDP/53 可走 TCP DNS；不保证完整系统 DNS/IPv6 防泄漏。
• 安装、重启不自动 Connect；没有自动节点切换或提供节点服务。

连接与诊断
• 应用、目标、端口、协议、规则、节点、状态；代理 TCP 终态有实测字节和耗时。
• 当前及上一份连接日志各约 8 MiB；搜索、分页、规则解释、JSON 导出。
• 精确应用诊断会话 10–600 秒，保留配置、时间窗和证据 ID；支持会话对比。
• 最多 20 会话、每个 5,000 条/8 MiB、总计 128 MiB；不静默删除旧会话。
• 记录缺失、历史淘汰、同步/连续性不足明确显示；closed/bypassed 不代表 HTTP 成功。

HTTP(S) 抓包
• 精确应用、1–20 个主机、1–16 个 TCP 端口，用户批准 30–600 秒。
• HTTPS 需显式信任设备本地 CA；不自动绕过证书固定。
• 请求/响应保留脱敏 JSON / JSON-SSE 样本，支持 HTTP/2 与增量 SSE。
  每侧最多 64 KiB；任意文本/二进制、无效编码或超大结构化正文会注明未保留。
• 最多 1,000 条请求、总计 128 MiB；GUI 最近 200 条，Agent 可分页。
• HTTP 错误、状态分布、耗时、慢请求；同应用时间窗对比；缺少连接证据会注明。
• AI 接口：保留样本中的 model、API 返回的 token 用量、SSE 数据帧及实测首响应字节。
  不估算 token，不把首字节等同首 token，不提供内置模型推理。
• 分享默认仅元数据；GUI 可明确包含脱敏样本并在导出前预览；MCP 报告不含正文。
• Agent 正文权限独立批准、可撤销，到期受限；抓包结束后可保留最多十分钟读取期。
• 脱敏是尽力处理；任意响应可能回显秘密，不能保证完全匿名化或无秘密持久化。

Header 改写
• 请求和响应 Set / Add / Remove；精确应用、主机、端口、路径前缀、可选方法。
• 最多 32 条，顺序执行；替换值存 Keychain，每次明确启用后只在对应抓包会话生效。
• 路径是编码后的字面前缀，不是正则或路径段匹配，不含查询及 fragment。
• Header 名最多 128 ASCII 字节，值最多 4,096 ASCII 字节，路径前缀最多 2,048 字节。
  启动快照编码后还须小于 256 KiB；超限时需减少规则或缩短值。
• 拒绝 CR/LF、非法名字、路由/报文框架/编码/内部代理字段。
• Header 改写不依赖正文是 JSON；不支持的正文格式仍原样流式转发，仅不保留其样本。
• 可查看规则 ID、动作和脱敏变化。记录局部改写不等于服务端已收到。

Agent
• 本地 stdio MCP，共 36 工具。应用发现、准备、连接诊断、限时观察、会话与报告。
• 抓包和临时分流规则提案需 GUI 批准；Header 提案还需 GUI 填值并明确启用。
• 精确应用查询必须 app_id；跨应用工具必须明确选择；正文另需授权。
• 抓到的内容视为不可信数据，不是命令、规则批准或扩大权限的指令。

当前不含：完整 IP VPN、WireGuard/OpenVPN、Kill Switch、防泄漏承诺、自动故障切换、
QUIC/HTTP3 解密、gRPC 解码、WebSocket 帧调试、loopback 抓取、断点暂停编辑、
重放、Mock、E7、内置 AI，以及上游自签名根证书/mTLS 身份配置。
具体实测构建、系统和边界以 ACCEPTANCE-1.0.zh-CN.txt 为准。
