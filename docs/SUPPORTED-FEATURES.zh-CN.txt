0.4 日常代理工作区
- Direct / Rules / Global Proxy；节点或手动组、实际扩展配置确认。模式变化仅影响新连接。
- 菜单栏连接/断开、切换模式/出口、打开窗口。
- 节点搜索、单次与顺序批量 HTTP 检查；连接/总延迟、时间、失败阶段、旧配置标注，最多保留500项。
- HTTPS 订阅下载与更新预览、刷新时间、保留引用节点，忘记来源可保留节点。应用更新需断开，重连手动操作。
- 网络路径状态和变化提示；路径可用不证明互联网或节点可用。
- 普通代理不要求解密 CA；HTTP(S) 抓取另行批准。

Locus 0.3 HTTP(S) 正文证据能力

- Requests 按准确应用签名 ID、准确主机和 TCP 端口抓取；默认端口 80/443。
- 捕获窗口 30–600 秒；用户在界面明确批准。Agent 只能提出申请。
- HTTPS 需显式信任本机 Locus CA，也可由特定客户端自行信任公开 CA 文件。
  不自动安装证书；私钥保存在本机 Application Support，不随发行包分发。
- 请求/响应保留脱敏 JSON、JSON SSE 样本；支持 HTTP/2 与增量 SSE。
  每侧最多 64 KiB；任意文本/二进制、超限结构化正文及不支持的编码会注明未保留。
- 认证头、Cookie、常见敏感 JSON 字段、嵌套 JSON 字符串和 URL 查询值脱敏。
  常见数字型 AI token 用量计数保留。脱敏为尽力处理，不是匿名化或秘密检测保证。
- 请求有独立 ID、应用身份、连接 flow ID、实际节点/规则、HTTP 状态及完整性标记。
  可与已有诊断会话按应用和时间关联；缺少窗口内连接证据会单独标明。
- Agent 正文读取单独批准；初始授权到捕获结束后最多十分钟，可随时撤销。
  已保存的准确应用/主机/捕获范围也可单独授权十分钟，无需重新抓取或 Connect。
- 28 个 MCP 工具；新增申请、状态、请求分页、正文分页及结束捕获五个工具。
- 原有 Direct / Block / Proxy 和具体节点选择继续生效，不因抓取失败回退直连。
- 最多 1,000 条请求证据、总计 128 MiB；不自动删旧数据。界面显示最近 200 条，
  Agent 可分页读取全部保留元数据。原始未脱敏正文不会写入捕获文件。

限制：仅 TCP HTTP(S)；不解密 QUIC/HTTP3、gRPC、WebSocket 帧。暂不支持配置上游
自签名根证书或 mTLS 身份；证书固定应用可能拒绝抓取，不会自动绕过。loopback/
组播仍由系统排除；本地网络绕过策略继续生效。其他编码的正文可能不保留。

Locus 0.4.0 (59) 新增能力

保存会话：精确应用标识，10–600 秒，保存配置快照、窗口与证据 ID。
结束进入 finishing，等待覆盖截止时刻的扩展快照；停止或超时则明确提示尾部可能缺失。
最多 20 会话、单个 5,000 条/8 MiB、总计 128 MiB；不静默删除旧会话。
支持同应用会话对比、具体配置差异、脱敏报告、抓取自检及规则试算/新增前预览。

手动代理组：新连接使用当前成员，旧连接保留具体节点；事件记录组 ID 和节点。
真实节点测试：扩展内通过所选节点访问 example.com:80，不受默认路由替代。
失败无直连回退；阶段、HTTP 结果和耗时可查，不是带宽或应用成功指标。
托管订阅：HTTPS 手动刷新预览，稳定 ID，引用节点保护；需停止后应用，随后手动 Connect。

Agent：28 工具。新增会话 start/poll/finish、保存证据分页、比较、自检、规则试算、
节点测试 start/poll、临时规则提案。临时规则需 GUI 批准，新连接首优先，30–600 秒后
由扩展停止匹配；GUI 退出不取消到期检查。过时提案不可批准，不恢复旧的整份配置。

Locus 0.4.0 (59) 能力范围

规则：按应用签名标识、域名/子域名分流；Direct / Block / Proxy；顺序优先；
可暂停单条规则。缺少应用归属或原始域名时会保守选择，并注明证据不足。

代理：SOCKS5、HTTP CONNECT、Trojan、Shadowsocks AES-256-GCM 和
ChaCha20-IETF-Poly1305。支持节点凭据、代理链接、单次 HTTPS 订阅导入。
托管订阅支持手动刷新预览及引用保护；支持手动代理组，不自动刷新或故障切换。

TCP：第 26 版已通过五协议共 65 项受控运行检查，涵盖 IPv4/IPv6 目标、
认证拒绝及恢复、按应用分流、DNS，以及支持/明确拒绝普通 UDP 的路径。
125 条测试事件已与扩展原始记录和用户镜像逐条核对。
这不代表所有厂商、所有服务端配置或所有网络环境均已验证。

UDP：SOCKS5 和两种 Shadowsocks 支持 UDP 转发，取决于上游服务端能力。
HTTP CONNECT / Trojan 只将 UDP/53 DNS 转为 TCP 转发，其他 UDP 明确失败。

DNS：代理路由中的私有 DNS/53 目标可改写至设置的公共解析器。
不解密 DoH/DoT，不提供本地域名分割解析，不承诺所有系统 DNS 无泄漏。
默认绕过本地网络，但 DNS/53 仍有专门的代理路由处理。
系统 configd 的 DHCPv4 UDP/67、DHCPv6 UDP/547 固定交回系统直连，
避免应用代理规则破坏地址获取或续租；此例外不包含普通应用或 DNS。

连接记录：应用标识、域名或 IP、端口、TCP/UDP、规则与动作、状态和错误。
代理 TCP 终态记录包含实际测量的字节数、耗时和流 ID。
支持保留日志搜索、详情和 JSON 导出。日志仅保留当前及上一份，每份约 8 MiB。
记录淘汰、同步不完整和已知连续性缺口会在相关工具结果中说明。

Agent：本地 stdio MCP。列举运行应用、检查抓取状态、按应用限时观察、
搜索记录、解释当前规则与历史证据、汇总返回记录或滚动时间窗口。
精确诊断工具要求应用、主机、端口与协议四项，一次返回当前预测、匹配历史
统计及最近失败/阻断证据；搜索默认最多返回 20 条，可显式分页。
当前提供 28 个工具：应用搜索/解释要求 app_id；跨应用搜索和未知身份解释
使用独立工具，避免遗漏参数时扩大范围。已安装 helper 的真实 HTTPS 抓取、
搜索、路由与摘要一致；一次 Goose/Qwen4B 16k 案例的核心事实通过，
但模型仍存在措辞矛盾，详见已知限制。其他客户端需自行完成权限及兼容验收。

当前不包含：任意格式正文抓取、HTTP 重放/改写、内置 AI 模型、E7 脚本、
WireGuard / Hysteria / MASQUE 等其他隧道协议、网关、远程控制面板、自动恢复。
它使用 Network Extension 实现透明代理，不是通用 VPN 协议客户端。
