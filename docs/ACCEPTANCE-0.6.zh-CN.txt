Locus 0.6.0 (68) 公开预览验收范围

最低系统 macOS 26.0，Apple silicon。实际虚拟机系统为 macOS 26.6.2 (25G83) 和 macOS 27.2.1 (26B131)；不代表已测过 26.0 或实体 Mac。

两台虚拟机安装同一份 Developer ID 签名、Apple 公证并附票的 ZIP：
Locus-0.6.0-68.zip
SHA-256: 86632ca036558b4a5deabcc220b9e20b76959fa0b62df87d1eda866ce544d02f

新增能力：请求/响应 Header Set、Add、Remove；精确应用、主机、TCP 端口、路径前缀及可选方法匹配；值在 Keychain；每次抓包默认关闭改写，需人工再次勾选。Agent 只能提议匹配元数据，不能提交替换值或批准生效。总计 36 个 MCP 工具。

本版验证：
- 146 个核心测试、7 个 Python Header 规则测试、14 套签名 MCP 集成测试。
- 冻结引擎真实 HTTP/HTTPS、HTTP/2、增量 SSE、上游不受信证书拒绝、权限及存储回归；256 次 TLS Header 请求，8 个并发工作线程。
- 双系统真实 Network Extension：升级保留数据、默认不改写与主动启用对照、请求 Set/Add/Remove、响应 Set/Remove、重复头、范围不匹配、HTTPS、增量 SSE；用独立服务端 nonce/Header/连接来源核对。
- 抓包结束后立即发起普通请求及 16 个并发请求；改写全部停止，Global 代理继续。另测 30 秒到期、SSE 中途强制引擎退出、启动取消与重新连接。
- 各 10 次手动断开/连接；访客网卡断网/恢复；代理节点不可用时失败且未偷偷直连；SOCKS5 与 HTTP CONNECT 均实测，普通 HTTPS 无额外 CA 参数。
- macOS 26：持续代理 1800 秒、7008 次成功 nonce 回显。macOS 27：1802 秒、7000 次。每批 8 个请求，批间暂停 2 秒；不是饱和吞吐或长时抓包压测。结束时事件写入失败为 0、记录同步正常。
- 双系统实际冷启动：配置、规则与已保存证据保留，不自动连接、不自动抓包/改写、不恢复 Agent body 授权；手动连接并再次勾选后，原 Keychain 值生效。
- 清理测试规则及其 Keychain 值，恢复原始配置字节，移除本次生成的 CA 私钥；无残留抓包/Agent body 授权，未向系统或登录钥匙串添加测试 CA 信任。

范围：以上是有界的公开预览验收，不是全天候可靠性认证。实体机、真实休眠唤醒/Wi-Fi 漫游、多日运行、macOS 26.0、完整 UDP/DNS/DHCP/IPv6 新一轮矩阵及本版 Trojan 全链路重测仍未完成。0.6 HTTPS 测试使用客户端指定 CA，系统钥匙串信任/移除操作未在本版重测。

本产品是规则代理和有授权边界的 HTTP 调试工具，不能承诺完整 VPN、全流量覆盖、Kill Switch 或防泄漏。不支持暂停断点编辑、重放、Mock、任意请求体/URL 修改或内置 AI 推理。证书固定应用可能无法解密；正文脱敏是尽力处理，服务端可能把 Header 值回显到正文。

复核源码、测试与原始运行证据留在私有源码仓库/本地，不随公开发行仓库发布。
