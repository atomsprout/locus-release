Locus 0.3.0 (50) 首次体验验收与反馈

仅在测试者自己的 Mac 上执行。目标为 Apple silicon / macOS 26.0 或更新版。
这是待执行的清单，随包提供清单不代表这些步骤已在你的机器上通过。

[ ] 记录芯片、macOS 版本、是否曾安装过 Locus、是否运行其他网络工具。
[ ] 校验应用 ZIP，解压后用 Finder 拖入 Applications，从该位置打开。
[ ] 完成原生扩展和代理配置授权，保持默认 Direct，手动 Start。
[ ] 状态显示 capture active；实际访问网页并在 Connections 找到对应记录。
[ ] 配置自己的可用代理，验证实际访问；记录协议和服务端类型，不记录密码。
[ ] 默认 Direct，为一个应用添加 Proxy 规则；另一个应用仍按默认路由访问。
[ ] 暂停并恢复规则，观察新连接的路由变化；旧 TCP 会话可保持原路由。
[ ] 在 MCP 客户端添加配置，完成该客户端的共享数据授权；按应用抓取，
     再搜索和解释返回记录，检查摘要是否对应同一批事件。
[ ] 诊断时核对应用、主机、端口、协议及记录 ID；bypassed 不等于请求成功。
[ ] 跨过至少一次实际 DHCP 租约续租，确认地址和网络持续可用；
     检查系统 DHCP 记录，不要用一次打开网页代替续租验证。
[ ] 点击 Stop，确认 Not running，检查正常直连网络仍能访问。
[ ] 重启 Mac，确认没有自动抓取；手动打开并 Start 后检查记录保留和新连接。
[ ] 若做升级，先记录旧版本、规则及历史；升级后验证保留和手动 Start。
[ ] 如需卸载，用 Settings → Remove network integration，按系统要求确认或重启；
     确认停用后再删除应用，并检查普通网络可用。

0.3 正文功能补充体验清单
[ ] 准备并显式信任本机 CA；确认没有自动信任。
[ ] 审阅准确应用、主机、端口和期限；Agent 正文读取默认不批准。
[ ] 实际 JSON 请求和 SSE 流式响应可见，状态/完整性/截断说明明确。
[ ] 其他应用、主机和端口保持原有网络策略。
[ ] 未批准正文访问时工具拒绝；批准后可分页读取；撤销或过期后再次拒绝。
[ ] 结束抓取后仍可在显示期限内分析旧正文，不再产生该范围的新正文样本。
[ ] 拷贝证据前检查敏感字段；不要把 URL 路径/IP 等当作完全匿名数据。
[ ] 移除 CA 信任；之后如需再解密必须显式重新信任或配置客户端 CA。
