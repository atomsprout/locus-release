Locus 0.6.0 (68) 首次体验与反馈

安装与日常代理
[ ] Apple silicon、macOS 26 或更新；从 /Applications 打开。
[ ] 手动 Connect，完成系统网络扩展/代理配置允许步骤。
[ ] 配置自己的节点，在 Overview 选择 Direct / Rules / Global。
[ ] 检查网页、开发工具、按应用分流，以及节点不可用时的错误提示。
[ ] 反复 Disconnect/Connect，休眠唤醒、网络切换、DHCP 获取/续租后再试。
[ ] 重启后不自动连接；手动打开应用、Connect 才应用保存的代理模式。

抓包与 Header 改写
[ ] Requests → HTTPS certificate settings，准备本地证书；需要 HTTPS 时显式信任。
    支持指定 CA 文件的客户端也可仅为该客户端信任，不必加入系统信任。
[ ] New inspection 选择准确的应用/Helper 签名 ID、主机、TCP 端口和时间窗。
[ ] 重建连接并复现请求，查看状态、完整性、请求/响应和 SSE；其他正文可能被省略。
[ ] Header rewrites → New rule，填写准确应用、主机、端口、编码路径前缀、
    可选方法，以及请求/响应、Set/Add/Remove 和 Header。Set/Add 的值进入 Keychain。
[ ] 保存规则后普通代理流量不变；新抓包默认不勾选 Apply matching header rewrite rules。
[ ] 明确勾选后核对匹配列表，再开始抓包。用自己的服务端日志/回显确认实际收到的值；
    改写记录本身只证明本地处理，不能代替服务端确认。
[ ] 验证 Set 替换、Add 重复字段、Remove 全部同名字段；未匹配请求保持原样。
[ ] Finish inspection 后等待停止确认，再立即请求：普通代理应继续，改写应停止。
[ ] 需编辑规则时先结束抓包，再开始新的明确批准范围。没有断点暂停/逐条手动编辑功能。

Agent 与分享
[ ] 按 MCP.example.json 接入客户端；先发现应用和检查准备，再提出抓包申请。
[ ] Agent Header 提案仅包含匹配条件；在 GUI 审核、填值、保存，并在抓包中明确启用。
[ ] 正文读取单独批准、可撤销；元数据和 Header 提案不会自动获得正文权限。
[ ] 用请求/连接 ID 核对诊断和同应用会话对比；不要把 closed/bypassed 当成 HTTP 成功。
[ ] 分享前预览。默认元数据报告省略目标、Header 和正文；脱敏并不保证匿名。

卸载
[ ] 先 Disconnect；如曾信任本机 Locus CA，先在证书设置移除信任。
[ ] Settings → Remove network integration，按系统提示完成可能需要的重启。
[ ] 再 brew uninstall --cask atomsprout/tap/locus。不要手动删除系统扩展目录。
